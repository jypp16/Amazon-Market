# Matriz de Diferencias: Documentación vs. Frontend y Base de Datos Actual

**Proyecto:** Amazon-Market  
**Sprint:** 2 — Fase 1 (Preparación y contratos)  

Esta matriz registra expresamente las diferencias detectadas entre:
1. `10 Historias de Usuario (1).pdf` (HU-07 a HU-10)
2. `.docs/Análisis de Requerimiento - Sprint 2.docx`
3. `.docs/acuerdos-modulo-compras.md`
4. El diseño real del frontend (`Views/Inventario/ajustes.php`, `Views/Reporte/kardex.php`, `Views/Reporte/variaciones.php`, `Views/Producto/*`) y el estado actual del backend/base de datos.

> **Regla rectora (Acuerdos 2 y 3):** Prevalecen los acuerdos confirmados para el Sprint 2. Se conserva el diseño, columnas y filtros actuales del frontend, con la única excepción de la adición expresamente autorizada del selector **“Sentido del movimiento”** en `Views/Reporte/variaciones.php` (Fase 7).
